# Cardápio — Espetinho da Dedé

Cardápio digital estático e responsivo do Espetinho da Dedé.

## Executar

Requisitos: Node.js 22.13 ou superior e pnpm.

```bash
pnpm install
pnpm dev
```

Abra a URL exibida no terminal.

## Build

```bash
pnpm build
```

## Alterar produtos e preços

Edite o arquivo `src/data/menu.ts`. A página é montada automaticamente a partir dos dados desse arquivo.

O logo oficial está em `public/assets/logo-espetinho-da-dede.png`.
